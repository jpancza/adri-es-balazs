## Még teendő a feltöltés előtt

Az `index.html`-ben a következő helyőrzőket kell lecserélni valódi adatokra:

- `RSVP_ENDPOINT_IDE` — a Google Apps Script webalkalmazás URL-je (lásd korábbi utasítás a beszélgetésben)
- Telefonszámok (Adri, Balázs) a Kontakt szekcióban és a szállás-tippben
- Visszajelzési határidő dátuma
